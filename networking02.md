## EC2 Instance (Server)
1. EC2 has different terminologies on different platforms
    * Instance -> AWS 
    * Compute Engine -> GCP
    * VM -> Microsoft Azure 
2. This is the most important part, the cost of your instance on monthly basis depends heavily on the region you choose to rent a server in. Mumbai it is 4.66$/Month and for the same configuration is it 1.67$/Month in Ireland and 2.77$ in  Africa.
